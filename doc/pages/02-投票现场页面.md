# 投票现场页面（观众 / 评审 / 大屏）

## P3 观众投票 H5 `/vote/{code}`

**用途**：现场观众扫大屏二维码投票。code 为轮次级短码。

```
┌─────────────────────────┐
│ 投票主视觉 Banner         │
│ {投票名} · 第Y轮           │
│ ⏱ 投票进行中 剩余 04:32   │  未开始/已结束显示对应状态文案
├─────────────────────────┤
│ 我的剩余票数：3 / 3        │
├─────────────────────────┤
│ ┌──────┐ ┌──────┐       │
│ │照片  │ │照片  │        │  选手卡片两列网格
│ │01 张三│ │02 李四│       │  编号+名称（+单位/地区小字）
│ │[投票]│ │[投票]│        │
│ └──────┘ └──────┘       │
│ ┌──────┐ ┌──────┐       │
│ │ ...  │ │ ...  │        │
│ └──────┘ └──────┘       │
├─────────────────────────┤
│ （开放时）查看当前结果 →    │
└─────────────────────────┘
```

- 点"投票"：即时反馈（按钮变色+剩余票数-1+轻震动+按钮弹跳微动画）；不可重复投同一人时该卡片按钮变灰
- 票数用尽：顶部横幅"已投完，感谢参与"
- 结果查看由后台开关；开放时可看柱状图（只读）
- 防刷：优先微信 openid（有认证服务号），否则设备指纹+IP+图形验证码

## P4 评审评分页 `/judge/{token}`

**用途**：专家评审与大众评审共用。token 定位"轮次×群体×评审"。

**首次打开（仅要求绑定的群体，如大众评审）**：
微信扫码 → 静默绑定（openid 或设备指纹）→ 进入评分页；
之后该 token 仅在被绑定微信中可用，转发/换设备提示"此评分码已绑定其他微信"。
专家评审（iPad 由礼仪小姐操作）不强制绑定，直接进入。

```
┌───────────────────────────────┐
│ {投票名}·第Y轮 │ 专家评审       │
│ 评审：王老师                   │
├───────────────────────────────┤
│ ┌───────────────────────────┐ │
│ │ 01 张三                    │ │
│ │      [ − ]   92   [ + ]    │ │  打分型：超大步进器，长按快调
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ 02 李四                    │ │
│ │      [ − ]   88   [ + ]    │ │
│ └───────────────────────────┘ │
│              ...              │
├───────────────────────────────┤
│ 已评 8/8      [ 确认提交 ]     │  底部固定栏：进度+大按钮
└───────────────────────────────┘
```

- 打分型（评分群体）：每选手 0~满分步进器；未打满全部选手时提交，红色高亮漏项提醒
- 投票型（限名单投票群体）：卡片勾选，显示"已选 X / 最多 N"
- 提交：确认弹窗（"提交后不可修改"）→ 成功页"✓ 已提交，感谢评审"，token 即刻失效
- iPad 适配：大字体大点击区、禁双击缩放、防误触（提交需二次确认）

**细分评分表单**（群体启用细分时替换上述单总分卡片）：

- 每个评分项独立输入，空白与显式 0 分开；填了一半必须补齐，完全未触碰的选手在确认框中明确提示按 0 分计。
- `逐人填写`：选手导航 + 当前选手全部评分项，适合 iPad 横屏逐项核对；`多人同页`：展开当前批次全部选手，适合集中录入。两种视图共享同一状态，切换不提交、不丢分。
- 视图偏好按评委 token 保存在当前设备；草稿按 token、轮次、群体、批次与评分规则签名隔离，刷新可恢复，切批次不串分，规则变化后拒绝恢复旧草稿。
- 提交确认逐人列出合成总分；断网失败保留输入并可重试。成功后只读回显逐项原始分、贡献和合成总分。
- 完整页面线框见 `pages/05-细分评分.md`。

## P5 大屏页 `/screen/{roundId}`

参考 `doc/references/活动现场专业评委评分结果.jpg`、`活动现场投票结果.jpg`、`活动现场的投票入口二维码.jpg`。

**模式一 · 二维码模式**（拉票时段）：

```
┌─────────────────────────────────┐
│      {投票名} · 第Y轮 投票评选    │
│      ┌─────────────────┐        │
│      │    巨型二维码     │        │
│      └─────────────────┘        │
│           扫码投票               │
│        ⏱ 剩余 04:32            │
└─────────────────────────────────┘
```

**模式二 · 图表模式**（实时票数/结果）：

```
┌─────────────────────────────────────────┐
│                {投票名}           ●实时 16:20:33│
│                {轮次} · {群体名}                  │
│ 群体类型：投票群体 │ 参与：141人 │ 权重：20%      │
├─────────────────────────────────────────┤
│      ▇  ▇  ▇  ▇  ▇  ▇  ▇  ▇          │  彩色柱状图（ECharts）
│    32   29  18  15  14  11   8   4     │  柱顶：票数/平均分
│   4.54 4.11 2.55 2.13 1.99 1.56 ...    │  副标：折算分数
│   01-  02-  03-  04-  05-  06- ...     │  底部：编号+名称，45° 旋转
└─────────────────────────────────────────┘
```

- 默认按当前显示维度降序；评分群体柱顶显示平均分，投票群体显示票数+折算分
- 标题第一行仅显示居中的评选名称，第二行居中显示轮次名与当前类型名；总分时类型名为“总分揭晓”
- 控制台可独立隐藏 Y 轴数值/刻度/横向刻度线，以及柱顶“折算/分数”副数值；副数值开关不影响主数值和名次
- **键盘控制**（沿用参考系统习惯，用户已确认）：
  - `Q` 或 `2`：显隐二维码模式
  - `←` / `→`：切换群体（专家评审 → 大众评审 → 观众评审 → 总分）
  - `R`：显隐结果数值（主持人控节奏）
  - `F`：全屏（首屏常驻一行操作提示，5 秒淡出）
- 数据：SSE 推送，票到即动（柱形缓动+数字滚动）；断线自动重连，"●实时"变灰警示
- 也可由 B10 大屏控制台远程切换（操作员笔记本控制，大屏无人值守）
- 视觉：深色底高对比、柱色按设计规范色板；1920×1080 起步等比缩放；观看距离 3m+ 可读的字号下限
