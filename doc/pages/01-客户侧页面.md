# 客户侧页面（公开，免登录，移动优先）

## P1 视频合集页 `/v/{code}`

**用途**：核心刚需。一个分组 = 一个链接，分组页即入口（无上层活动页）。
布局对标视频号合集页（参考 `doc/references/视频号分组视频播放展示.jpg`）。

```
┌─────────────────────────┐
│      分组封面 Banner      │  16:9 主视觉（后台可传，缺省用首视频封面）
├─────────────────────────┤
│ 高效办成一件事             │  分组名
│ 共 29 个视频        [分享] │  分享→底部弹层：二维码大图+复制链接
├─────────────────────────┤
│ 1 ┌──────┐ 标题标题标题…  │
│   │缩略图 │ …两行截断      │
│   └──────┘ ♡可省  12:35  │
│ 2 ┌──────┐ 标题标题标题…  │
│   │缩略图 │ …          08:12│
│   └──────┘                │
│ 3 ...                     │
├─────────────────────────┤
│ 成都广播电视台 · 技术支持   │  页脚品牌（可后台开关）
└─────────────────────────┘
```

- 列表项：序号、16:9 缩略图、标题（两行截断）、时长；按后台排序
- 分组设访问密码时：先出密码门（简洁输入框+确认），通过后可看（记 sessionStorage，刷新不重输）
- 分组暂停：整页"内容暂未开放"（不渲染任何视频地址）
- 空分组："内容准备中"

## P2 视频播放页 `/v/{code}/play/{id}`

```
┌─────────────────────────┐
│                         │
│      <video> 播放器      │  16:9，原生控制条，微信内支持全屏
│                         │
├─────────────────────────┤
│ 视频标题                 │
│ 所属分组 · 时长           │
├─────────────────────────┤
│ 同分组 · 接着看            │
│ [缩略图] 下一条标题  12:35 │
│ [缩略图] 再下一条    08:12 │
└─────────────────────────┘
```

- MP4 由 Nginx 直接分发（Range 拖动播放）；点击条目无刷新切换（history API）
- 视频下架或分组暂停：回退 P1 并提示
- 不提供下载按钮（UI 不引导下载）

## 客户侧通用规范

- SSR 首屏直出；微信内置浏览器兼容性优先；弱网懒加载缩略图
- 品牌一致性：封面/标题/页脚视觉统一，色彩遵循 `04-设计规范.md`
- 加载失败给重试按钮；播放失败提示"请切换网络后重试"
- 分享卡片文案（微信转发时的标题/摘要）= 分组名 + 视频数，便于运营直接转发
