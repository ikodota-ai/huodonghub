# 管理后台页面（/admin，桌面优先）

## 整体框架

```
┌──────────────────────────────────────────────┐
│ 顶栏：系统名 │ 面包屑        全屏 ⛶ │ 管理员 ▾ │
├──────────┬───────────────────────────────────┤
│ 侧导航    │                                   │
│ ▤ 仪表盘  │                                   │
│ 🎬 视频分组 │            内容区                │
│ 🗳 投票评选 │                                   │
│ ✦ AI 能力 │                                   │
│ ⚙ 系统设置 │                                   │
└──────────┴───────────────────────────────────┘
```

- 品牌：成都广播电视台 CDRTV（登录页与顶栏；登录页参考 `doc/references/投票评分系统-管理员登录.png` 的居中卡片）
- 侧导航可收起为图标；全局视觉遵循 `04-设计规范.md`

## B1 登录页 `/admin/login`

居中卡片：台标 + "活动配套管理系统" + 用户名/密码 + 登录。失败 5 次锁定 10 分钟。

## B2 仪表盘 `/admin`

- 统计卡：视频分组数（视频总数·占用空间）/ 进行中投票 / 本地媒体目录用量
- 管理员专属「存储运行状态」卡：独立调用 `GET /api/settings/storage/usage`，不阻塞原仪表盘；维护人员与编辑不显示，接口返回 403。
  - OSS 模式显示只读健康状态、当前 Region/Bucket/非空对象前缀、前缀对象数与容量；只分页统计当前前缀，**不是整个 Bucket，也不是流量或账单**。
  - 本地残留只统计 `MEDIA_ROOT/images`、`covers`、`videos` 普通文件，忽略符号链接，不含 `tmp/backups`，用于判断是否仍可能由 Nginx 本地直发。
  - 成功结果按驱动、Region、Bucket、前缀缓存 10 分钟；「刷新」携带 `?refresh=1` 强制重查，配置变化自动失效，失败不缓存。
  - 本地模式、配置未完成、权限异常、连接失败均在卡片内展示；不返回密钥、签名 URL 或其他前缀对象清单。
- "进行中"区：当前开放的投票轮次（一键进大屏控制台）+ 最近编辑的视频分组
- 快捷操作：新建分组、新建投票

## B3 视频分组列表 `/admin/videos`

- 卡片网格：封面、分组名、视频数、状态开关（开放/暂停）、更新时间、操作（管理/分享二维码/编辑/删除）
- 新建分组（弹层表单）：名称、封面、描述、访问密码（选填）、状态
- 分享弹层：合集链接 `/v/{code}` + 二维码下载（PNG，带分组名水印角标）

## B4 分组详情 `/admin/videos/{id}`

四个 Tab：**视频** / **链接导入** / **抢救** / **分享**

**视频 Tab（默认）**
```
┌────────────────────────────────────────┐
│ [上传视频]  共 12 个 · 3.2 GB            │
│ ┌────┬──────┬────┬────┬────┬────┐     │
│ │缩略│标题  │时长│大小│状态│操作│     │
│ │图  │…    │12:35│...│上架│…  │     │
│ └────┴──────┴────┴────┴────┴────┘     │
└────────────────────────────────────────┘
```
- 上传：多文件、分片断点续传、进度条；完成后自动 ffmpeg 流水线（状态：处理中→已就绪/失败可重试）
- 行操作：改名、拖拽排序、上架/下架、删除；来源标记（上传/导入/抢救）

**链接导入 Tab**
- 粘贴公众号文章链接 → 解析 → 列出文中视频（标题/时长/清晰度）→ 勾选导入
- 导入记录：来源链接、时间、状态；失败原因 + 转人工提示
- 固定文案：仅支持公众号文章链接，不支持视频号链接

**抢救 Tab**
- 左侧图文 SOP（下载助手公众号 / PC 微信工具两条通道）；右侧拖入上传 + 原视频号链接记录框（选填溯源）

**分享 Tab**
- 合集链接、二维码大图与下载、访问密码设置、分组状态开关、复制"转发文案"

## B5 投票列表 `/admin/votes`

- 卡片/表格：投票名称、轮次数、状态（彩排/正式/已结束/已归档）、创建时间、操作（管理/复制观众链接/归档/删除）
- 新建投票（弹层）：名称、封面、说明；创建后自动带一个"第一轮"，直接进入 B6
- 投票编辑中含**微信服务号配置**区：AppID / AppSecret（选填，不同投票可用不同公众号；配置后观众投票与大众评审绑定走 openid 网页授权，未配置降级设备指纹），附配置指引（需认证服务号 + 网页授权域名加入业务域名）

## B6 投票详情 `/admin/votes/{id}`

顶部：投票信息摘要 + 对外码中心（当前轮观众二维码、大屏链接，一站复制）。
Tab：**轮次** / **选手** / **评审** / **大屏控制台** / **结果**

- 投票设置中的活动状态不再使用可往返下拉框，仅提供“转为正式 / 结束活动 / 归档活动”单向操作。
- 转为正式前必须暂停所有进行中轮次，并逐轮清空全部彩排评分和投票；接口在同一事务中复查状态及流水，禁止跳级或退回。

## B7 轮次管理（投票详情默认 Tab）

- 轮次列表（左）+ 选中轮次编辑（右）：
  - 基本：名称、顺序、观众投票起止时间（可选手动开关）
  - **三群体勾选配置**（本页核心）：

```
┌──────────────────────────────────────────────┐
│ ☑ 专家评审     评分制  权重[60]%  满分[100]     │
│ ☑ 大众评审     评分制▾  权重[20]%  满分[100]     │
│              ☐ 需要扫码绑定微信（建议开启）       │
│ ☐ 观众评审     投票制  权重[20]%  每人[3]票     │
│              ☐ 允许重复投同一人                  │
│ ┌──────────────────────────────────────────┐ │
│ │ 权重合计 100%  ████████60███20███20██ ✓    │ │  比例条实时校验
│ └──────────────────────────────────────────┘ │
│ + 添加自定义群体                                │
└──────────────────────────────────────────────┘
```

  - 参赛名单：从选手库勾选本轮选手（B8 维护）
  - 大屏选项：默认显示群体、观众端是否开放结果查看
  - 评分群体可独立配置 `整体评分 / 分值分配 / 百分制加权`；细分支持 2～10 项、排序、满分或比例合计校验和实时试算。专家与大众规则互不串联，投票群体无评分项配置。
  - 历史待开始轮次无成绩可直接换规则，有测试成绩须先清空；轮次开始后评分规则锁定，暂停也不能修改，需要新规则时新建轮次。
  - 观众投票群体在彩排活动中显示“清空测试票（数量）”，不取决于轮次是否待开始；确认后仅清本群体票数、统计和提交状态，保留配置、选手、其他群体数据及评审绑定；无票时禁用。

## B8 选手库

- 投票维度表格：编号（自动生成 01/02…可改）、照片、名称、简介、排序、增删改、CSV 批量导入（模板下载）

## B9 评审管理

- 按"轮次×群体"切换；评审列表：姓名、类型（专家/大众）、绑定状态（未绑定/已绑定微信）、提交状态、操作（重置/解除绑定/删除/新增）
- 彩排活动的“重置”清除本人成绩、投票、绑定与提交状态，任意轮次状态均可执行；正式、结束和归档活动的“解除绑定”只处理设备，保留所有结果。非彩排活动已有评分或投票的评审不能删除。
- 每个评审：专属二维码 + 口令链接（`/judge/{token}`）
- **打印视图**：六宫格"姓名+二维码"一页排版，现场打印裁剪分发

## B10 大屏控制台

```
┌──────────────────────────────────┐
│ 轮次：第一轮 ▾   状态：[开始本轮]  │
├──────────────────────────────────┤
│ 当前开放群体（同步大屏显示）：       │
│  内容：(•)专家评审 ( )大众评审      │
│  ( )观众评审 ( )总分（关闭所有提交） │
│  [✓]显示结果数值  [✓]显示折算/分数 │
│  [✓]显示Y轴刻度  [ ]二维码模式     │
│  投票倒计时：[5:00] [启动]         │
├──────────────────────────────────┤
│ [打开大屏页] [复制大屏链接]         │
│ 观众入口二维码（下载）              │
├──────────────────────────────────┤
│ 迷你预览（大屏实时缩略画面）         │
└──────────────────────────────────┘
```

- 开始本轮/暂停本轮/结束本轮只控制当前轮次的现场节奏；控制台操作经 SSE 即时同步大屏。
- “当前开放群体”同时控制大屏显示和提交权限：只有选中的群体可评分/投票，切换立即影响页面和直接 API；选择“总分（关闭所有提交）”后所有群体仅可查看结果，不能继续写入。
- “显示结果数值”控制全部柱顶数值；“显示折算/分数”只控制评分群体“折算”和投票群体“分数”副数值；“显示Y轴刻度”同时控制 Y 轴数值、刻度、轴线和横向刻度线
- “清空彩排数据”仅彩排活动可用，轮次处于待开始、进行中、暂停或已结束均可执行，建议先暂停。正式、结束和归档活动禁用并由接口返回 409；清空全部评分、投票、统计和提交状态，保留配置、名单、二维码口令及绑定。

## B11 结果页

- 轮次选择 + **单轮结果表**：排名、编号名称、各群体明细（分数/票数、参与数）、总分；导出主结果 CSV 或逐项评分明细 CSV
- **跨轮聚合结果**（对标 `doc/references/成都分赛区聚合结果.pdf`）：
  - 统计卡：参赛选手数 / 聚合轮次数 / 最高总分 / 平均总分
  - 列表行：排名、编号+名称、总分、每群体一行明细（得分/票数占比，绿色权比小字）
  - 导出聚合结果（CSV）
- 逐评审明细抽屉：某选手被哪些评审各打了多少分（审计用）；细分群体先展示评分项平均与贡献，再展开每位评委逐项原始分、逐项贡献、合成总分和个人折算。
- 选手 Tab「成绩单」与评审 Tab「记录」使用同一数据口径；逐项 CSV 每行对应一位评委的一个评分项，含活动、轮次、选手、群体、比例、原始分、贡献、个人合成与折算、群体平均和群体折算，保留 UTF-8 BOM。

## B12 AI 能力导航（M4）

- 分类卡片：PPT 制作 / AI 图片 / 声音复刻 / 对口型 / 数字人口播；每卡含推荐工具、入口、SOP（Markdown 可编辑）
- 设置区：服务商 API Key 配置位（DeepSeek/火山/RunningHub/LibLib），仅存储

## B13 系统设置

- 用户管理：列表、新增、重置密码、停用（admin/editor，editor 无系统设置权限）
- 存储：媒体用量、Top10 大文件
- 备份：最近备份时间、立即备份（mysqldump+媒体打包）
