# 设计规范（Design System 基线）

> 以"高级网页设计工程师"标准制定，开发时逐页对照执行。

## 品牌与色彩

| Token | 值 | 用途 |
|---|---|---|
| brand-primary | 橙（取 CDRTV 台标，约 #F08300） | 主按钮、强调、选中态 |
| brand-deep | 深橙（hover 下沉一档） | 主按钮 hover/active |
| success / warning / danger | 绿 / 黄 / 红 | 状态语义 |
| ink-900→ink-300 | 深灰到浅灰 6 阶 | 文字层级 |
| screen-bg | #0B0B0F | 大屏深底 |
| screen-bar | 高饱和 10 色循环（蓝/绿/橙/红/青/紫…，对齐参考系统大屏柱色） | 大屏柱形 |

- 客户侧与后台：浅色底 + 白色卡片 + 品牌橙点缀；大屏：深底高对比
- 对比度满足 WCAG AA（正文 ≥4.5:1）；大屏按 3m+ 观看距离单独放大

## 字体与排版

- 字体栈：系统中文字体（PingFang SC / Microsoft YaHei / sans-serif），数字用等宽变体（表格票数对齐）
- 字号阶梯：后台 14 基准；客户侧 16 基准（标题 20/24）；评审页 18+；大屏按分辨率缩放（1920 下标题 ≥48、数值 ≥64）
- 行高 1.5~1.7；标题最多两行截断；间距 8pt 网格（4/8/12/16/24/32）

## 组件约定

- 按钮：主（橙）/ 次（描边）/ 危险（红）；高度后台 36、移动端 44、评审页 56+
- 卡片：圆角 12、轻投影、hover 微浮起（后台列表卡）
- 表单：标签上置、错误内联红字、必填星号；抽屉用于新建/编辑，弹窗用于确认
- 表格：斑马纹、操作列右置、空态插画+引导按钮
- 二维码弹层：居中二维码+链接复制+下载 PNG，三件套统一
- 骨架屏：所有异步列表首屏骨架，不用裸 loading 圈

## 动效（克制、150~250ms）

- 投票成功：按钮缩放弹跳 + 票数数字翻滚
- 大屏：柱形高度缓动过渡、数值滚动（不闪烁跳变）
- 页面切换：淡入；弹层：底部上滑（移动端）/ 中心缩放（桌面）
- 不做花哨入场动画，现场页面以稳定读数为第一优先

## 响应式断点

| 断点 | 场景 |
|---|---|
| <768px | 客户侧手机页（P1~P3）单列 |
| 768~1200px | 评审页 iPad 横竖屏自适应 |
| ≥1200px | 后台桌面布局 |
| ≥1920px | 大屏页等比缩放居中 |

## 各端专项

- **微信内 H5**：禁水平滚动；iOS 视频内联播放 playsinline；处理微信分享默认文案
- **iPad 评审页**：禁双击缩放、防误触二次确认、熄屏提醒文案
- **大屏**：无人值守可运行（SSE 自动重连、异常自动恢复）；键盘提示首屏淡出；远程可控
- **打印视图**：评审二维码六宫格 A4 排版，打印隐藏其余元素
