# 项目文档索引

## 这是什么

成都市广播电视台政商合作部的活动配套管理系统。部门以执行政商活动为主（现场拍摄/推流、舞台执行、播客录制、采访视频、公众号代维护、广告片、宣传短视频、PPT 制作），本系统为活动提供网络页面支撑。

## 核心背景（30 秒版）

- **痛点**：视频号分组播放页无法生成链接/二维码，只能在微信生态内分享；需要一个自己的平台按分组生成链接给客户看视频。
- **第二刚需**：多届、多轮的活动投票评分（评委 iPad 投票 1票=N分 + 观众扫码投票 1票1分 + 大屏实时柱状图 + 后台统计）。
- **组织方式**：两个独立功能模块（视频分组 / 投票评选），无贯穿层级，各自生成对外链接（2026-09-17 决策，废弃"活动贯穿"方案）。
- **预算**：零。服务器借朋友的阿里云，域名备案已有，可能申请单位子域名 CNAME 过来。
- **选型**：Next.js 全栈 + MySQL 5.7 + Nginx + pm2，无 Docker。否决了 RuoYi/Java/PHP，理由见 architecture.md。
- **远期**：AI 能力板块（PPT 生成、AI 图片、声音复刻、对口型、数字人短视频），先做工具导航+SOP，API 预留配置位（DeepSeek / 火山引擎 / RunningHub / LibLib）。
