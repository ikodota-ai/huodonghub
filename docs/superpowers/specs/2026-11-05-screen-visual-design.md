# 大屏视觉与活动主视觉背景设计（2026-11-05）

## 目标与边界

- 面向大型赛事与不规则超宽 LED，美化大屏背景、图表页标题区和扫码页。
- 专家评分、大众评审、观众投票、总分揭晓通过低亮度氛围色区分；主视觉负责活动品牌，氛围色负责当前内容识别。
- 保持计分、投票、SSE、键盘控制、ECharts 柱子和 dataZoom 行为不变；不做整屏高饱和换色，不牺牲远距离读数。

## 方案

采用“独立大屏主视觉 + 四类氛围色”。不复用手机端活动封面：手机封面比例可能不适合 LED。主视觉未上传、未启用或加载失败时，回退到纯氛围色背景。

## 视觉规范

- 基础底色 `#070B14`；标题使用系统中文字体（PingFang SC / Microsoft YaHei），数据使用 Arial + 表格数字。
- 专家/第一评分群体：琥珀金 `#D6A84F`；大众/第二评分群体：紫罗兰 `#8B7CF6`；观众投票群体：青蓝 `#28C7D9`；总分：酒红光晕 `#6B1E2E` + 香槟金 `#E7C77E`。
- 群体按当前轮次顺序识别：投票群体固定青蓝；评分群体中第一个对应专家色、第二个对应大众色；自定义后续评分群体沿用大众色。总分使用独立酒红金光晕。
- 背景层次：主视觉（`cover` 居中铺满）→ 可配置暗化层 → 当前类型低透明径向光晕 → 底部读数压暗渐变。柱子配色不变。
- 共用克制的顶部类型徽标与细光带，不添加循环飘动装饰；`prefers-reduced-motion` 下不增加环境动画。

## 二维码页

- 宽屏三栏：左侧活动名称/轮次/状态/倒计时，中间白底黑码卡片，右侧微信扫码三步提示与参与信息。
- 二维码尺寸受屏高与屏宽共同约束，保持正方形，远距离可扫；白底卡片不被主视觉或氛围色染色。
- 宽度不足或高度较低时切换紧凑居中布局，避免内容溢出；超宽屏增加左右信息间距而非拉伸二维码。

## 后台配置与数据

投票设置新增“大屏主视觉”区域：图片上传、启用开关、暗化强度 60%–90%（默认 78%）、移除图片；提示按现场 LED 实际分辨率导出，超宽屏使用超宽素材。

`votes` 新增字段：

- `screen_bg_enabled` TinyInt，默认 0：是否启用主视觉背景。
- `screen_bg_image` VarChar(255)，可空：独立大屏主视觉路径，使用现有图片上传与媒体分发。
- `screen_bg_dim` Int，默认 78：暗化百分比，限制 60–90。

投票详情 PUT/GET 增加三字段及归属校验；大屏 state API 返回生效的主视觉配置。无图或关闭时不影响旧页面。

## 验证

- tsc、eslint、生产构建通过。
- Playwright 分别检查专家、大众、观众、总分的图表页与二维码页。
- 1920×1080、2560×1080 超宽屏及低高度窗口无溢出、无二维码变形、文字与柱子清晰。
- 主视觉启用/关闭/移除、暗化强度保存与刷新生效；无图回退正常。
- 投票后仍停留当前群体并播放增长动画；控制台与键盘控制不回退。

## 自检

无占位项与待定项；配置字段、回退规则、群体映射、响应式规则和验收口径一致。范围仅大屏展示与投票级背景配置，不涉及计分及其他前台页面。
