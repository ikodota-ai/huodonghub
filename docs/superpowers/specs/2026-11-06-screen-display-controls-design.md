# 大屏标题与显示开关设计（2026-11-06）

## 目标

按已确认的方案 A，优化图表大屏标题层级，并为每个轮次增加两个独立、可持久化的显示开关。默认配置保持现有活动画面不变。

## 标题布局

- 第一行：评选名称居中，不再拼接轮次和群体。
- 第二行：`轮次名 · 当前类型名` 居中；类型名使用群体原名，总分时显示“总分揭晓”。
- 第三行：权重、参与率和批次信息居中，保持原有显隐规则。
- 实时状态、时间和倒计时保留右上角；中心标题限制宽度，避免与右侧信息重叠。
- 二维码页、背景氛围、图表柱子、投票与 SSE 逻辑不变。

## 轮次级开关

`vote_rounds` 新增：

- `screen_show_axis` TinyInt，默认 1：显示 Y 轴数值、刻度、轴线及横向刻度线；关闭后隐藏这些元素并缩小图表左边距。
- `screen_show_contribution` TinyInt，默认 1：显示柱顶副数值；关闭后仅隐藏评分群体的“折算：xx”和投票群体的“分数：xx”，主数值和名次不受影响。

两个开关位于大屏控制台“大屏显示内容”区域，按轮次保存并通过现有 SSE 同步。它们不改变“显示结果数值”总开关：总开关关闭时仍隐藏全部柱顶数值；副数值开关只控制副数值。

## 接口与兼容

- 投票详情、控制台 POST 和大屏 state API 增加 `screenShowAxis`、`screenShowContribution`。
- 控制台 POST 仅接受 0/1；大屏 state 输出 boolean；后台 RoundItem 使用 number。
- 使用 MySQL 5.7 兼容迁移，utf8mb4，不新增键盘快捷键，不改计分口径。

## 验证

- 未实现前 state API 缺少两个字段，控制台找不到对应开关。
- 迁移后默认值均为 1；分别 POST 0/1 并刷新，配置和 state 正确保持。
- 1920×1080、2560×1080 实拍居中标题；Y 轴和副数值开关即时生效。
- 总开关关闭仍隐藏所有柱顶数值；二维码页、群体切换、投票增长不回退。
- tsc、eslint、生产构建通过，测试配置恢复，进度写入 `doc/progress.md`。
